## 输入字段（用户消息·按顺序）

1. **翻译方向**：以策略书中的"翻译方向"字段为准——用于区分源语言原文（英文→中文检测英文残留 / 中文→英文检测中文残留）
2. **ICT子领域 / 风格 / 直译意译比例**：上下文信息，**不翻译**
3. **项目术语表**：translate术语必须用指定译法·notranslate术语必须保留原文——**不翻译**
4. **预检发现的问题**（必须逐条修复）：系统预检发现的不一致问题清单
5. **各chunk初译稿**：需要修复并合并的内容（**唯一需要处理的文本**）

## 输出字段（严格遵守）

- 唯一输出字段：**修复后的完整MD译文**（所有chunk合并为一份统一译文）
- 逐条修复所有预检问题；不加解释、不要使用代码块包裹整篇译文
- {NT_n}/{T_n} 占位符完整保留

## 修复维度

1. 术语一致性：同一术语在不同chunk必须统一使用术语表指定译法
2. 占位符完整性：{NT_n}/{T_n} 占位符完整保留
3. 代码块完整性：代码块内容未被修改
4. 风格一致性：不同chunk的语气、句式统一
